# TransformPro Spec — Navigation (spec §9)

> Part of the TransformPro specification. Core rules live in `/CLAUDE.md`; section numbers (§) refer to the original spec — see the index in CLAUDE.md.

## 9. Navigation

**Bottom tabs (5):**

1. **Home** (Dashboard)
2. **Members**
3. **Check-in** (big center button style)
4. **Payments**
5. **More**

**More tab menu** (grouped list with icons):
- Gym: Plans & Pricing, Personal Training, Services, Trainers & Staff, Branches
- Growth: Enquiries / Leads, Messages & Reminders, Referrals
- Money: Expenses, Reports
- Data: Backup & Restore, Import Members (CSV), Export Data, Trash, Activity Log
- App: Settings, Membership Card Design, Language, Theme, Lock Now, Switch User, Help / About

A **global search** (magnifier in header on Home & Members) searches members by
name, phone, member code; enquiries by name/phone.

A floating **"+" quick-action button** on Home opens: Add Member, Record Payment,
Mark Attendance, Add Enquiry, Add Expense.
